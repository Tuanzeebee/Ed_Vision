## Temporary Placeholder

Until you add real thumbnails, you can:

1. Use screenshot from YouTube videos using the videoId from `liveThemes.ts`
2. Create placeholder images using any image editor
3. Use stock photos from Unsplash that match the theme mood

## Image Requirements

- Format: JPG or PNG
- Aspect Ratio: 16:9 (e.g., 400x225, 800x450, 1280x720)
- Max file size: < 200KB per image for optimal performance
- Quality: Medium to High (don't need 4K for thumbnails)
